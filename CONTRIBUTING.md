# Contributing

Thank you for improving EasyPDF. Open an issue before a large architectural change. Keep changes focused, add tests for behavior and hostile inputs, preserve offline/privacy guarantees, and do not introduce a dependency without documenting its license and security rationale.

Run `dotnet format --verify-no-changes`, `dotnet build -c Release`, and `dotnet test -c Release` before submitting. By contributing, you agree that your contribution is licensed under the project's MIT License.
